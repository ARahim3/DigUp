DigUp

Describe it. Dig it up.

  • Screenshots and photos “that payment error”, “the zebra”, “whiteboard from Tuesday”
  • PDFs and documents “the clause about pets in the lease”, “flight receipt”
  • Moments inside audio and video “where they talk about sleep”, “the part with the drums”

Everything is indexed and searched on this computer. DigUp downloads its AI model (865 MB) once; after that it works offline, and nothing you index ever leaves your computer.

What should DigUp search?

Pick folders, and open one to leave out some of its subfolders. The first pass reads everything once; after that DigUp keeps up with changes as they happen.

DigUp only reads files: it never changes, moves or uploads them.

Search your code too?

DigUp can find code by what it does: type “code:” in the search panel and say what you're looking for. Code gets an index of its own and shows up only when you search for code. Pick the folders that hold your code, or leave them all and turn it on later in Settings.

DigUp reads what git keeps (not dependencies or build output). The time is reading it once; after that, only what changes is read again.

Search from anywhere

Press the shortcut in any app to open the search panel, and describe what you remember.

In the search panel

↩
opens the file (at the page or moment, where it can)
Ctrl+↩
shows it in its folder
↑ ↓
move between results
Space
shows the one you moved to big
Esc
closes the panel

You're all set

DigUp lives in the tray, which shows how indexing is going. Closing this window doesn't stop it.
