Download DigUp

Free and open source. The app is small; the model ({{ site.model.download }}) downloads once, on first launch, while you pick the folders to search.

Mac

DigUp for Mac

{{ ('Version ' ~ latest.mac.version) if latest.mac else 'Stable' }}

Needs {{ site.requirements.mac }}. Signed with a Developer ID and notarized by Apple.

{{ file_card(latest.mac, 'Download for Mac', true) }}

Or with Homebrew:

{{ command(site.homebrew) }}

Install

  1. Open the DMG and drag DigUp to Applications.
  2. Open DigUp. While the model downloads, pick the folders to search; each shows how long its first pass will take.
  3. Press ⇧⌘Space in any app and describe what you're looking for.

Windows

DigUp for Windows

{{ ('Beta ' ~ latest.windows.version) if latest.windows else 'Beta' }}

Needs {{ site.requirements.windows }}. Installs for you only, with no admin rights.

{{ file_card(latest.windows, 'Download the installer', true) }}
{{ icon('warn') }}

Windows may say it protected your PC, because the installer isn't signed yet. Choose More info, then Run anyway.

Install

  1. Run the installer. It adds DigUp to the Start menu and the tray.
  2. Open DigUp. While the model downloads, pick the folders to search. A quick check decides whether the model runs on your graphics card or the processor.
  3. Press CtrlShiftSpace in any app and describe what you're looking for.

  1. Install the .deb with apt (the package is called dig-up), or make the AppImage executable and run it.
  2. Open DigUp. While the model downloads, pick the folders to search.
  3. Press CtrlShiftSpace. On GNOME and KDE under Wayland, DigUp adds it to the desktop's keyboard settings during setup.

Every file comes from GitHub Releases, which shows each one's SHA-256; the ones above are copied from there. Compare with shasum -a 256 on a Mac or Linux, or certutil -hashfile <file> SHA256 on Windows. Updates are signed, and an installed copy refuses one that isn't.

{{ icon('refresh') }}Updates

DigUp checks once a day and installs a new version with one click: the Mac app, the Windows installer and the AppImage update themselves. With the .deb, DigUp opens the release page for you. How updates and betas work
