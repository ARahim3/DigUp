DigUp searches the files on your computer by what's in them. It runs {{ site.model.by }}'s {{ site.model.name }}, a model that puts text, pictures, sound and video in one shared space, so a description in your own words finds the photo, the PDF page, the minute in a recording or the moment in a video.

New here? The [one-minute product video]({{ site.video.url }}) shows it in use. Then install it, pick a few folders, and press the shortcut. Everything below is for when you want to know more, and [Troubleshooting](/docs/troubleshooting/) has fixes for the problems people run into. Press <kbd>/</kbd> on any page to search all of it.
